Kết Quả Đối Chiếu Hóa Đơn Nhập Hàng

Dữ liệu được so khớp bằng thuật toán FIFO và Chuỗi mờ thông minh.

Tổng Đơn Nhập 0 Đơn hàng nhập từ Sapo
Đã Khớp Khít 0 100% khớp hóa đơn
Lệch Giá / SL 0 Có sai số về tiền hoặc SL
Chưa Có Hóa Đơn 0 Không thấy hóa đơn của NCC
Thiếu MST NCC 0 Cần bổ sung MST trên Sapo
